Meta-Analysis Automation Tool

메타분석 자동화 도구 — 체계적 문헌고찰 전 과정 자동화 웹 애플리케이션

체계적 문헌고찰(Systematic Review)과 메타분석은 최고 수준의 근거(Evidence)를 생산하는 연구 방법이지만, 한 편을 완성하는 데 평균 6개월~1년이 소요됩니다. 문헌 검색, 중복 제거, 수천 편의 논문 스크리닝, 데이터 추출, 통계 분석, 보고서 작성 등 반복적이고 시간 소모적인 과정이 대부분입니다.

이 도구는 PICOS 연구 질문 정의부터 PRISMA 2020 보고서 생성까지 전 과정을 자동화하는 웹 애플리케이션입니다. 6개의 독립적인 에이전트가 파이프라인을 구성하며, 5개 학술 DB API 연동, 3단계 지능형 중복 제거, AI 기반 스크리닝, R 통계 엔진 연동, 출판용 PRISMA 흐름도 자동 생성 등의 기능을 제공합니다.

앱 메인 화면 — 사이드바 네비게이션 + PICOS 프로젝트 설정

Python 3.11+ Streamlit (9 Pages) SQLite (7 Tables) R 4.x (metafor) pandas matplotlib rapidfuzz httpx biopython

1 프로젝트 설정 — PICOS 정의

PICOS 프레임워크를 사용하여 연구 질문을 구조화합니다. 여기에 입력한 PICOS가 이후 모든 단계의 기준이 됩니다 — 검색 쿼리 생성, 스크리닝 판정, 데이터 추출, 보고서까지 일관되게 연결됩니다.

I중재 (Intervention)로봇 보조 재활 치료
C비교군 (Comparison)전통적 재활 치료

S연구 설계 (Study design)무작위 대조 시험 (RCT)

2 검색 전략 — 6종 DB별 검색식 생성

검색 전략은 두 가지 모드를 지원합니다.

자동 생성 모드 — 내장 한→영 의학 용어 매핑 테이블 기반으로 PubMed/Cochrane/Embase/자연어 4종 쿼리 즉시 생성. 빠르지만 테이블에 없는 주제는 한계.

Claude 활용 모드 — 6종 DB(PubMed, WoS, Embase, CINAHL, Cochrane, SCOPUS)별 구문 규칙이 포함된 체계적 프롬프트 생성. MeSH, Emtree, CINAHL Headings 등 DB 고유 문법 자동 적용. 어떤 주제든 고품질 검색식.

Claude가 반환한 JSON을 붙여넣으면 7개 DB 탭에 자동으로 채워지며, 사용자가 수정 후 저장할 수 있습니다.

검색 전략 사용법 안내 — 쿼리 팁 + 작업 방법

검색 필터 설정 + 자동 생성 / Claude 활용 모드 선택 + 쿼리 확인 및 수정

3 문헌 검색 — 5개 API + 3단계 중복 제거

5개 학술 DB API를 동시에 검색하고, 결과를 자동으로 수집합니다.

DB특징레코드 수

OpenAlex오픈 학술 데이터250M+

3단계 지능형 중복 제거:

1. DOI 정확 매칭 (정규화: strip, lowercase)

2. 제목 퍼지 매칭 (rapidfuzz, 유사도 ≥ 90%)

3. 제1저자 + 출판연도 복합키 → 제목 유사도 ≥ 75%

총 3,789편 수집, 624편 중복 제거 → 3,165편 스크리닝 대상 + 5개 DB 동시 검색

PubMed 쿼리 확인 + Cochrane/Embase 수동 CSV 가져오기

4 스크리닝 — 3단계 선별 워크플로우

단계기준판정
1차: 제목/초록PICOS 기본 부합 여부포함 / 제외 / 보류
2차: 전문상세 PICOS + 연구 태그 분류포함 / 제외 / 보류
3차: 정밀 선별최종 적격성 평가포함 / 제외

작동 방식: 100건 단위로 CSV 배치 파일을 내보내고, Claude에 스크리닝 프롬프트와 함께 전달합니다. Claude가 각 논문의 PICOS 부합 여부, 신뢰도(0~1), 배제 사유를 판정하면 결과 CSV를 다시 가져옵니다. API 호출 없이 LLM 품질의 판정을 얻는 방식입니다.

3단계 스크리닝 메트릭 — 1차 492편 포함, 2차 262편, 3차 51편 최종 포함

1차 제목/초록 스크리닝 — Claude Max용 CSV 배치 내보내기/가져오기

5 검증 및 수동 검토

AI 스크리닝 결과의 품질을 검증하는 단계입니다.

  • AI 검증 탭: 포함 판정된 문헌 중 10~100%를 랜덤 샘플링하여 사람이 직접 재판정. 일치율/민감도/특이도 확인.
  • 문헌 직접 검토 탭: 포함 문헌을 하나씩 읽고, 키워드/페이지네이션으로 필터링.
  • 판정 변경 탭: 개별 문헌의 AI 판정을 수동으로 include/exclude 변경, CSV 일괄 변경 가능.

AI 스크리닝 검증 — 일치율 100%, 민감도 100%, 특이도 0.0% (검증 표본 10/197편)

검증 및 수동 검토 사용법 안내 — AI 검증, 문헌 직접 검토, 판정 변경 3개 탭

7 데이터 추출 + Risk of Bias 2.0

포함된 문헌에서 연구 특성과 결과 변수를 추출합니다.

  • 연구 특성: 연구 설계, 국가, 대상자 수, 연령, 성별 비율
  • 중재 정보: 중재 유형, 상세 내용, 기간, 비교군
  • 결과 데이터: 평균/표준편차(연속형), 사건수/전체수(이분형), 위험비(생존)

8 통계 분석 — Python-R 브릿지

Python-R 브릿지를 통해 R의 metafor 패키지로 통계 분석을 수행합니다.

  • 주 메타분석: 8종 효과 크기(OR, RR, MD, SMD, HR 등) × 8종 모델(FE, REML, DL 등)
  • 이질성 검정: Q-통계량, I², τ²
  • 출판 편향: Egger's 회귀 검정 + Trim-and-Fill 보정
  • 하위그룹 분석: 범주형 변수별 효과 크기 비교
  • 민감도 분석: Leave-one-out, 모델 비교, 높은 RoB 제외
  • 메타회귀: 연속형 조절변수의 효과 검정

Python에서 JSON으로 데이터를 전달하고, R이 분석 수행 후 결과 JSON + 플롯 이미지를 반환하는 브릿지 구조입니다.

통계 분석 사용법 — 자동 생성 결과물 (Forest/Funnel Plot, Egger's, Leave-One-Out)

R 4.x 연동 — R이 미설치된 경우 안내 메시지

기술적 차별점

Claude 연동 — API 비용 $0

API를 직접 호출하지 않고, 프롬프트 자동 생성 → 사용자가 Claude에 복붙 → JSON 결과 파싱 방식을 채택. 스크리닝, 데이터 추출, 검색 전략 생성 모두 이 방식으로 동작하여 AI 품질의 결과를 비용 없이 활용합니다.

3단계 지능형 중복 제거

DOI 정확 매칭 → 제목 퍼지 매칭(rapidfuzz 90%) → 저자+연도 복합키 매칭의 3단계를 거쳐 정밀도와 재현율을 동시에 확보합니다.

Python-R 브릿지

메타분석의 사실상 표준인 R의 metafor 패키지를 Python에서 활용하기 위해, JSON 기반 양방향 데이터 교환 브릿지를 구현. 6개 R 스크립트가 Forest Plot, Funnel Plot, RoB 시각화, 하위그룹/민감도/메타회귀 분석을 수행합니다.
